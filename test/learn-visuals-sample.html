Visual system sample sheet

Every primitive from src/learn-visuals.js, rendered once. This page is for looking at, and for screenshots in a review. It is not linked from the app and it collects nothing. Motion runs only when you press a button, which is the rule the app follows too: nothing animates on first paint.

Roles and legend

Five meanings, each with a shape rule, so the drawing survives greyscale, colour blindness and a black and white print. The legend is generated from the same table the drawings use.

box and arrow

A pipeline: private key, public key, hashed, address. Straight arrows with labels.

branch

One parent, two children. This is hardened against normal, and the xpub reach question, drawn the same way every time.

group

A labelled container, for a chain family or an address format group.

chart

The randomness comparison. Logarithmic, because the rows span 2^9 to 2^128 and a linear axis would make every weak row invisible next to the strong ones, which is the opposite of the lesson. The reader's own value is outlined and marked, not only coloured.

trace

One value followed through a diagram. The end state is readable without watching, so the motion carries nothing on its own.
